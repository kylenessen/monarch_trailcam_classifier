# Monarch Trailcam Classifier

This repository contains the image-classification software and original cell annotations used in the western monarch monitoring study at Vandenberg Space Force Base.

The [Electron application](electron-app/) contains the classifier source code. The [illustrated classification guide](https://kylenessen.github.io/monarch_trailcam_classifier/) describes the labeling procedure. The [original classification JSON files](data/classifications/) preserve cell positions, butterfly categories, sunlight labels and saved annotations for 12 deployments.

The [USGS data release](https://doi.org/10.5066/P13IEKEB) provides the photographs, deployment metadata, wind and temperature observations, and image-level BI summaries and category counts. The native JSON files are hosted in this repository and are not attachments to the data release. The [manuscript repository](https://github.com/kylenessen/monarch-wind-light-manuscript) contains analysis inputs, scripts and results.
