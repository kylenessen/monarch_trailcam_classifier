# One-image example deployment

[UDMH2](UDMH2/) contains `UDMH2_20240105142001.JPG` and `configurations.json`. Copy this folder elsewhere, then select that copy in the application. No OneDrive account or full photograph archive is required.

The photograph is an unchanged copy of the existing OCR sample in `python-tools/extract-temp/sample_images`. The configuration contains the same image's original record from `data/classifications/UDMH2.json` and its stored 18-by-32 grid dimensions. The image record is unchanged, including its original sequence index. This is a one-image subset for demonstrating the interface, not a new classification or an analysis input.

Enter your initials and use Unlock to edit a copy. Back up `configurations.json` before experimenting. The source annotation archive remains authoritative. See [reuse notes](../REUSE.md) for the distinction between the software license and study materials.
